<h3 align="center"><code>MISSION</code></h3>

<p align="center">
  A professional software platform designed to connect
  <b>industrial infrastructure with modern web technology</b>.
</p>

<p align="center">
  GIZA combines real industrial data acquisition with authentication,
  APIs, dashboards, historical data, reporting and platform administration.
</p>
